## 🔧 需要后端补充的接口清单

### **高优先级接口**

#### **1. 时间段对比接口**
```http
GET /api/timecomparison/yearly_comparison/?account_id={id}
GET /api/timecomparison/weekly_comparison/?account_id={id}
```
**用途**: 对比页面的时间段对比图表
**数据要求**: 年度/周度资产变化、收益率、增长率

#### **2. 地区对比接口**
```http
GET /api/areacomparsion/area_comparison/?account_id={id}
```
**用途**: 对比页面的地区分布图表
**数据要求**: 各地区资产分布、收益率、投资比例

### **中优先级接口**

#### **3. 资产类别分布接口**
```http
GET /api/asset-category/?account_id={id}
```
**用途**: 资产总览页面的分类展示
**数据要求**: 各行业/板块资产占比、市值、收益率

#### **4. 时间序列接口**
```http
GET /api/time-data/?account_id={id}&start_date={date}&end_date={date}
```
**用途**: 资产总览页面的趋势图表
**数据要求**: 指定时间段内的资产变化、市值、收益率

### **低优先级接口**

#### **5. 风险指标接口**
```http
GET /api/risk-metrics/?account_id={id}
GET /api/risk-warnings/?account_id={id}
```
**用途**: 风险阈值和风险预警组件
**数据要求**: VaR值、最大回撤、波动率、风险警告
