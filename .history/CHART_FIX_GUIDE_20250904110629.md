# 图表显示问题修复指南

## 问题描述
图表组件无法正确显示真实数据，无论是否连接后台平台都显示相同的内容。

## 问题根源分析

### 1. 前端 API 调用问题
- **问题**: `ChartSection.vue` 组件完全使用硬编码的随机数据
- **原因**: 没有调用任何真实的API接口
- **影响**: 图表数据与后端完全脱节

### 2. 模拟数据功能干扰
- **问题**: 项目包含大量模拟数据功能
- **原因**: `mockData.js` 文件提供虚假数据
- **影响**: 即使API正常，也可能显示模拟数据

### 3. 图表数据绑定失败
- **问题**: 图表组件没有正确绑定API数据
- **原因**: 缺少数据加载和错误处理机制
- **影响**: 图表无法动态更新

## 解决方案

### 步骤1: 移除模拟数据功能
```bash
# 删除模拟数据文件
rm src/api/mockData.js
rm src/components/layout/MockDataIndicator.vue
rm src/components/layout/DataModeToggle.vue
```

### 步骤2: 重写图表组件
- 更新 `ChartSection.vue` 组件
- 添加数据加载状态
- 实现错误处理机制
- 连接真实API数据

### 步骤3: 创建专用图表API
- 新建 `src/api/chartApi.js`
- 定义各种图表数据接口
- 统一错误处理

### 步骤4: 更新组件调用
- 修改 `StrategyExecutionResult.vue`
- 移除硬编码数据
- 使用真实API调用

## 修复后的功能

### 1. 图表数据动态加载
- 组件挂载时自动加载数据
- 显示加载状态指示器
- 支持手动重试加载

### 2. 错误处理机制
- API调用失败时显示错误信息
- 提供重试按钮
- 详细的错误日志记录

### 3. 真实数据连接
- 连接国金平台后台数据
- 实时数据更新
- 支持多种图表类型

## API接口要求

### 后端需要提供以下接口：

#### 1. 策略图表数据
```
GET /api/strategy-chart/
Response: {
  legend: ['基准收益', '策略收益', '超额收益'],
  xAxis: ['01-01', '01-02', ...],
  yAxisName: '收益走势(%)',
  series: [
    {
      name: '基准收益',
      type: 'line',
      data: [10, 15, 20, ...],
      smooth: true,
      itemStyle: { color: '#00a2ae' }
    },
    // ... 其他系列
  ]
}
```

#### 2. 系统健康检查
```
GET /api/health/
Response: { status: 'ok', timestamp: '2025-01-01T00:00:00Z' }
```

#### 3. 策略执行结果
```
GET /api/execution-result/
Response: {
  keyMetrics: [
    {
      metricName: '总收益率',
      metricValue: '+8.2%',
      description: '当前策略累计收益率'
    }
    // ... 其他指标
  ]
}
```
